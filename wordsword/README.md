# Wordsword — English B2 → C1 (итерация 1)

Мобильное PWA: теория, тренировки (Learning Mode), контрольные (Exam Mode), словари, Case Lab, карта причин ошибок, Dashboard и CSV/JSON-экспорт. После первого открытия работает без интернета. Учебный прогресс хранится в IndexedDB на устройстве и никуда не отправляется.

**Состав этой сборки:** блоки 1–4 из 18 (Времена, Неправильные глаголы, Модальные, Conditionals), словари General 200 / Business 100 / Irregular 120 и исходный AI Agents 123, Case Lab (68 заданий в 6 форматах), Theory Check, смешанный экзамен, 30-дневный маршрут. Блоки 5–18 будут добавлены в следующих итерациях. Подробности — в `docs/REPORT.md`.

## Установка на телефон

Приложению нужен **HTTPS**: так работают service worker, офлайн-режим и установка. Подойдёт любой статический хостинг: GitHub Pages, Netlify, Cloudflare Pages.

### GitHub Pages
1. Распакуйте ZIP и загрузите **содержимое** папки `wordsword` в корень репозитория: `index.html`, `sw.js`, `manifest.webmanifest`, папки `css`, `src`, `vendor`, `icons`. Папки `tests`, `tools`, `docs` и файл `package.json` для работы приложения не нужны, но не мешают.
2. Откройте Settings → Pages → Deploy from a branch → `main` / root.
3. Через 1–2 минуты откройте `https://<имя>.github.io/<репозиторий>/`.

### Android (Chrome)
Откройте адрес, затем ⋮ → «Установить приложение» (или «Добавить на главный экран»).

### iPhone (Safari)
Откройте адрес в Safari, затем «Поделиться» → «На экран „Домой“». Запускайте приложение с иконки.

На iPhone у веб-приложения отдельное хранилище: прогресс в Safari и в установленной иконке не общий. Учитесь в одном месте и регулярно делайте резервную копию: «Прогресс» → «Резервная копия JSON».

## Обновление
1. Замените файлы на хостинге.
2. Если меняли код или контент, перед загрузкой выполните `node tools/build.mjs`. Скрипт пересоберёт `sw.js` с новым хешем версии, и телефоны получат обновление при следующем открытии онлайн.

Обновление **не стирает прогресс**: данные лежат в IndexedDB, а не в кэше. Удаляются только старые кэши файлов `wordsword-*`.

## Сохранность данных
- Каждое действие сохраняется сразу; в шапке «Сегодня» есть индикатор «Сохранено ЧЧ:ММ:СС».
- Приложение запрашивает `navigator.storage.persist()`. Это снижает риск, что браузер сам очистит данные, но **не гарантирует** сохранность. Данные пропадут, если очистить данные сайта или удалить приложение, а также если ОС освободит место.
- Резервная копия: «Прогресс» → «Резервная копия JSON». Импорт сначала проверяет файл и просит подтвердить замену данных.
- Прогресс старого vocab-app переносится автоматически, если новое приложение открыто **по тому же адресу**: localStorage привязан к адресу.

## Экспорт CSV
«Прогресс» → «Экспорт CSV» (за выбранный период) или «Полный CSV». Создаются 4 файла:
- `weekly_summary_YYYY-MM-DD.csv`
- `test_attempts_YYYY-MM-DD.csv`
- `answer_events_YYYY-MM-DD.csv`
- `error_map_YYYY-MM-DD.csv`

Формат: UTF-8 с BOM, даты ISO 8601. Где браузер это поддерживает, файлы передаются через меню «Поделиться» (на iPhone — «Сохранить в Файлы»); иначе скачиваются в «Загрузки».

## Для разработчика
```
node tools/validate.mjs        # проверка контента + отчёт покрытия (exit 1 при ошибках)
node --test tests/*.test.mjs   # unit-тесты (нужен npm-пакет fake-indexeddb: npm i -D fake-indexeddb)
node tools/build.mjs           # пересборка sw.js (список файлов + версия кэша)
python3 tests/e2e/e2e_main.py  # браузерные сценарии (pip install playwright; playwright install chromium)
```
Сборка не нужна: исходники — нативные ES-модули, React/htm лежат в `vendor/`. Структура и схемы данных описаны в `docs/ARCHITECTURE.md`.
